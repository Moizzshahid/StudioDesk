# Product vision

StudioDesk is a calm, context-aware operating system for independent creative studios.

**Promise:** projects move forward without losing the preferences, decisions, and reasoning that shaped the work.

## Differentiator: Studio Memory
- Client preferences
- Brand rules
- Creative decisions and rationale
- Feedback patterns
- Lessons learned

Memory is explicit and user-authored in this release. Future AI retrieval must respect workspace permissions and must not silently invent or save facts.

## Principles
1. Clarity over clutter.
2. Context is an asset.
3. Client relationships are more than CRM rows.
4. Useful defaults, no fake functionality.
5. Privacy boundaries are foundational.
